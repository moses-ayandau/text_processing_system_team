## Introduction
The **Text Processing and Data Management Tool** is an advanced Java application designed to provide robust solutions for text manipulation and data organization. It leverages regular expressions (regex), Java collections, and JavaFX to offer an intuitive user experience for developers, researchers, and data analysts. The project is developed in two parts:

1. Part One focuses on implementing core functionalities like regex operations, data management using collections, and a JavaFX-based user interface.
2. Part Two emphasizes team collaboration using Scrum methodology and Git/GitHub workflows, ensuring high-quality code and effective teamwork.

---

## Project Objectives
### Part One Objectives:
- Master the construction and usage of regular expressions (regex).
- Learn the fundamentals of Java collections (e.g., ArrayList, Set, Map) and their applications.
- Develop proficiency in creating user interfaces using JavaFX.
- Implement advanced programming concepts to build complex software systems.

### Part Two Objectives:
- Foster collaboration and adherence to Scrum practices within a team.
- Implement GitFlow branching strategy and utilize Git/GitHub effectively.
- Write descriptive commit messages and conduct thorough code reviews.
- Evaluate teamwork and communication skills in an agile environment.

---

## Features Overview
### Part One Features:
#### 1. Regular Expressions (Regex) Module:
- Search, match, and replace text using regex.
- Support for regex patterns with sets, ranges, alternations, shorthand notations, and quantifiers.
- User-friendly interface for inputting patterns and text data.

#### 2. Text Processing Module:
- Search for patterns and replace characters in text using regex.
- Display matched results and replaced text.
- Utilize Java's `Pattern` and `Matcher` classes for robust regex operations.

#### 3. Data Management Module:
- Manage collections using Java collections (ArrayList, Set, Map).
- Create, update, and delete entries in collections.
- Implement `hashCode` and `equals` methods for custom objects.

#### 4. User Interface:
- Interactive UI using JavaFX.
- Input fields for text and regex patterns.
- Display results and collection manipulations clearly.

### Part Two Features:
#### 1. Scrum Implementation:
- Conduct sprint planning, daily standups, sprint reviews, and retrospectives.
- Assign and rotate Scrum roles (Scrum Master, Product Owner, Development Team).

#### 2. Git and GitHub Workflows:
- Follow GitFlow branching strategy for organized development.
- Utilize pull requests for code reviews.
- Resolve conflicts collaboratively.

#### 3. Collaboration Practices:
- Effective communication via Slack or similar tools.
- Shared code ownership and accountability.
- Knowledge sharing and team discussions.

## Usage Guide
### Part One:
1. **Regex Operations:**
   - Navigate to the Regex Module.
   - Enter text and regex patterns.
   - Perform search, match, or replace operations.
   - View results in the output panel.

2. **Data Management:**
   - Access the Data Management Module.
   - Add, update, or delete entries in collections.
   - Use the interface to visualize collection data.

3. **UI Interaction:**
   - Input data through intuitive text fields.
   - Click buttons for desired operations.
   - Review displayed results.

### Part Two:
1. **Scrum Workflow:**
   - Participate in sprint planning and assign tasks from the backlog.
   - Use GitFlow to manage branches.
   - Commit changes with descriptive messages.
   - Conduct pull requests and code reviews.

---

## Development Workflow
### GitFlow Strategy:
1. **Main Branch:** Contains production-ready code.
2. **Develop Branch:** Contains code under development.
3. **Feature Branches:** Created for new features.

## Scrum Implementation
### Sprint Schedule:
- **Duration:** 4 hours per sprint.
- **Standups:** 15-minute meetings every 2 hours.

### Roles:
- **Scrum Master:** Facilitates meetings and removes impediments.
- **Product Owner:** Manages the backlog and priorities.
- **Development Team:** Implements features and ensures quality.
